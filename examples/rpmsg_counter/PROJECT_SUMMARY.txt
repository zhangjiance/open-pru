================================================================================
  项目概述
================================================================================

这是一个完整的 PRU-ICSS RPMsg 通信示例，展示了：
1. PRU 固件如何通过 RPMsg 协议与 Linux 通信
2. 如何实现定时周期性数据发送（每秒一次）
3. 如何优化 PRU 代码以适应 16KB IRAM 限制
4. 端点地址动态协商机制
5. 完整的编译、部署和调试流程

================================================================================
  核心功能
================================================================================

✓ PRU 端:
  - 每秒发送递增计数器值（0, 1, 2, ...）
  - 格式: "PRU Counter: XXXXX"
  - 通道: "rpmsg-raw", 端口: 30
  - 频率: 333 MHz
  - 代码大小: ~5 KB

✓ Linux 端:
  - 打开 /dev/rpmsg0 设备
  - 发送 "START" 触发消息
  - 接收并打印计数器消息
  - 显示接收统计信息

  关键技术亮点
================================================================================

1. 代码大小优化
   ✓ 避免使用 printf/sprintf (节省 ~18KB)
   ✓ 自定义轻量级字符串处理函数
   ✓ 最终代码仅 5KB，远低于 16KB 限制

2. 端点地址动态协商
   ✓ PRU 等待接收首条消息学习 Linux endpoint
   ✓ 无需硬编码地址，适应动态环境
   ✓ 解决 "msg received with no recipient" 问题

3. 精确延时实现
   ✓ 基于 333 MHz 时钟的空循环延时
   ✓ 经过实测校准的延时参数
   ✓ 可调节发送频率

4. 完整的 RPMsg 生命周期
   ✓ 初始化传输层
   ✓ 创建通道
   ✓ 等待驱动就绪

================================================================================
  部署方式
================================================================================

方式一: 自动化脚本（在项目根目录）
  $ ./deploy_counter.sh
  - 自动编译固件和接收程序
  - 自动上传到目标设备
  - 自动重启 PRU
  - 验证设备就绪

方式二: 手动步骤（在项目根目录）
  1. make clean && make
  2. scp firmware/am62x-sk/pruss0_pru0_fw/ti-pru-cgt/generated/*.out root@192.168.7.2:/lib/firmware/am62x-pru0-fw
  3. ssh root@192.168.7.2
  4. echo start > /sys/class/remoteproc/remoteproc1/state
  5. /tmp/rpmsg_counter_receiver
